Streamlit AI Agents
A collection of AI-powered Streamlit apps built with Python and OpenAI.   

Document RAG Agent (doc_rag.py): Upload PDFs, DOCX, or TXT files and ask questions grounded in your documents.

Multi-Agent System (multi_agent_system.py): A 3-agent pipeline (Research, Analyst, Report) for structured research.

Research Agent (research_agent.py): Searches the web and generates summarized reports with citations.

Security Log Agent (security_log_agent.py): Analyzes log files for threats and recommends mitigation steps.
